# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

Be respectful and professional. Harassment, hateful language, or abusive behavior will not be tolerated.

If you experience or witness unacceptable behavior, please contact the maintainers at kordalek@naver.com.

For the full text, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
