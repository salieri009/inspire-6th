# src

React 애플리케이션의 실제 소스 코드가 들어가는 최상위 폴더입니다.

이 폴더 아래에는 화면 진입점, 공통 스타일, 재사용 컴포넌트, 기능 단위 코드, 페이지 단위 코드가 위치합니다.

주요 하위 폴더 역할은 다음과 같습니다.

- `api`: 백엔드와 통신하는 API 관련 코드
- `components`: 여러 화면에서 재사용하는 공통 컴포넌트
- `features`: 특정 업무나 기능 단위로 묶은 코드
- `pages`: 라우팅 단위의 화면 컴포넌트

`index.js` 는 애플리케이션 진입점이고, `index.css` 는 전역 스타일을 관리합니다.
