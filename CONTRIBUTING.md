# Contributing

Thank you for your interest in contributing to this project.

- Issues: Please open issues for bugs or feature requests with a clear title and steps to reproduce.
- Branches: Use descriptive branch names: `feature/xyz`, `fix/issue-123`, `chore/docs`.
- Commits: Keep commits focused and use conventional messages (e.g., `feat:`, `fix:`, `docs:`).
- Pull Requests: Include a short description, related issue number, and testing notes.
- Tests: Add or update tests when adding features or fixing bugs. Run existing tests before submitting.
